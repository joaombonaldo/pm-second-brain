# Cap bulk edit at 100 listings per batch

## Decision

[decision] The first release caps bulk edit at 100 listings per batch. — 2026-10-06, Ana Souza

## Context

- [interpretation] Marco thinks large batches would hit the marketplace rate limit (around 50 requests per second,
  untested). — 2026-10-06
- [observation] Sellers edit between 20 and 80 listings at a time (Priya, from interviews). — 2026-10-06
